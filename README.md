## Note

*Vyper is in proof-of-concept stage.*

## Installation

* `rye add vyper --git https://github.com/flywheelhq/vyper`

## Development

* `git clone https://github.com/flywheelhq/vyper.git`
* `cd vyper`
* `rye sync`

## Contributing

Vyper is in early development. We will start accepting PRs soon once has stabilised a little. However, please join the [discussions](https://github.com/flywheelhq/vyper/discussions), add [issues](https://github.com/flywheelhq/vyper/issues), and share your use-cases to help steer the design.

## Flywheel

Science needs better software tools. [Flywheel](https://flywhl.dev/) is an open source collective building new tools to preserve scientific momentum, inspired by devtools and devops culture.
